## Required release records

Keep source URLs, pinned revisions, original split and record identifiers, original file hashes, image attribution (creator, original URL, license and version), license texts/notices, and all transformations. Describe typed instruction adaptations and sampling independently of source annotation licenses. Keep original evaluation roles when authors did not name a split; an S1MB test label must not imply an author-held-out test split.

For COCO and YFCC-derived images, resolve the individual image license and creator before redistributing blobs. For NLVR2 and RVL-CDIP, retain acquisition instructions and access conditions until image redistribution permission is established. For noncommercial/share-alike sources, preserve applicable restrictions and identify them in the dataset README. Screenshot application and website content can have rights separate from the dataset repository license.

Original compressed image bytes may be stored in SHA-256-deduplicated Parquet Image columns for reproducibility. Storage format does not change license conditions. Preserve originals separately from provider-specific resized or padded payloads, and identify the latter by checksum and transform policy. Do not publish restricted images merely because another benchmark mirrors them.

The complete candidate inventory is a local research draft, with no public dataset release implied. Question/answer and source image families may have separate terms; ambiguous scopes above remain unresolved.
